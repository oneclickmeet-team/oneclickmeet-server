# 원클릭밋 서버 | OneClickMeet Server

> 흩어진 데이트 장소를 모으고, 원하는 방문 순서에 맞춰 코스를 구성하는 모바일 서비스의 백엔드 서버입니다.

원클릭밋은 여러 플랫폼에서 발견한 맛집·데이트 장소를 모아두고, 방문 순서와 카테고리에 맞는 장소를 추천받아 코스를 편집·저장하는 서비스를 목표로 합니다. 개인으로 이용하다가 상대와 연결해 선택한 장소와 코스를 함께 관리할 수 있도록 개발하고 있습니다.

이 저장소는 회원·장소·코스·공유 기능의 API와 데이터 관리를 담당합니다.

## 1. 해결하려는 문제와 이용 흐름

여러 플랫폼에서 찾은 장소를 다시 찾아보고, 함께 갈 장소를 고르고, 방문 순서와 예상 금액을 따로 정리해야 하는 과정을 한곳에서 이어가려 합니다.

목표 이용 흐름은 다음과 같습니다.

**장소 모아두기 → 방문 순서·카테고리 선택 → 장소 추천 → 코스 편집·저장 → 함께 확인**

실제 서버 기능의 동작 시연은 아직 이 문서에 수록하지 않았습니다.

### 개발 예정 기능

아래 상태는 현재 확인한 서버 브랜치를 기준으로 합니다.

| 기능 | 목표 동작 | 서버 구현 상태 |
|---|---|---|
| 장소 모아두기 | 링크·스크린샷·직접 검색으로 찾은 장소를 확인하고 개인 보관함에 저장 | 예정 |
| 코스 추천 | `점심 → 액티비티 → 저녁`처럼 사용자가 정한 순서와 카테고리에 맞춰 장소 추천 | 예정 · 상세 규칙 설계 필요 |
| 코스 편집·저장 | 장소 추가·교체·삭제·순서 변경 후 코스를 저장하고 다시 조회 | 예정 |
| 장소·코스 공유 | 연결한 상대와 선택한 장소·코스를 공유하고 편집 | 예정 |
| 예상 금액 정리 | 사용자가 입력한 메뉴·활동별 2인 합계 금액 중 체크한 항목만 합산 | 예정 |

가격·메뉴 자동 수집, 결제·정산, 예산에 맞춘 추천은 현재 MVP 범위에 포함하지 않습니다.

## 3. 시스템 구조와 기술 스택

목표 시스템은 모바일 앱, Spring Boot 서버, MySQL로 구성합니다.

```text
모바일 앱
   │
   │ HTTP API — 구현 예정
   ▼
Spring Boot 서버
   │
   │ 데이터 조회·저장 — 기능별 구현 예정
   ▼
MySQL
```

현재 저장소에는 Spring Boot 애플리케이션 진입점, 로컬 MySQL 실행 설정, datasource 설정이 있습니다. 회원·장소·코스 등의 도메인 코드와 API는 아직 포함되어 있지 않습니다.

### 기술 스택

| 구분 | 기술 | 현재 적용 상태 |
|---|---|---|
| 언어 | Java 21 | 빌드 설정 |
| 프레임워크 | Spring Boot 4.1.1 | 기본 애플리케이션 구성 |
| 웹 API | Spring Web MVC | 의존성 추가 |
| 데이터 접근 | Spring Data JPA · MySQL Connector/J | 의존성 및 로컬 연결 설정 |
| 인증·검증 | Spring Security · Validation | 의존성 추가, 기능 구현 예정 |
| API 문서·상태 확인 | springdoc-openapi 3.1.0 · Actuator | 의존성 추가, 접근·노출 설정 검증 필요 |
| 로컬 DB | MySQL 8.4 · Docker Compose | 실행 설정 파일 구성 |
| 빌드·테스트 | Gradle Wrapper 9.7.1 · JUnit Jupiter | 빌드 및 테스트 실행 설정 |

의존성 추가와 설정 파일의 존재는 해당 기능의 구현·동작 검증 완료를 의미하지 않습니다.

## 4. 현재 구성과 개발 기준

### 로컬 개발 환경

Spring 애플리케이션은 로컬에서 실행하고, MySQL은 Docker Compose로 실행하도록 구성했습니다.

- DB 접속 정보는 환경변수로 전달합니다.
- 로컬 DB 포트는 기본적으로 `3306`이며 `MYSQL_PORT`로 변경할 수 있습니다.
- 로컬 프로필은 `ddl-auto: create-drop`을 사용합니다.
- 로컬 데이터는 재생성 가능한 개발 데이터로 취급합니다. Docker 볼륨을 사용하더라도 애플리케이션의 테이블 재생성·삭제는 발생할 수 있습니다.

### 기능 구현에 적용할 기준

다음 항목은 합의한 개발 기준이며, 현재 구현된 기능을 설명하는 것은 아닙니다.

- 업무별 코드는 `domain`, 공통 설정·예외 처리·기반 엔티티는 `global`에 배치합니다.
- 요청·응답 DTO는 분리하고 `record`를 사용합니다.
- 성공 응답은 DTO를 직접 반환하고, 오류 응답은 `ProblemDetail`을 사용합니다.
- 엔티티 전체에 대한 setter와 Lombok `@Data` 사용을 피합니다.
- 트랜잭션과 도메인 간 의존성은 각 기능의 요구사항에 맞춰 설계합니다.

세부 기준은 [개발 컨벤션](docs/conventions.md)에서 관리합니다.

## 5. 로컬 실행과 테스트

### 사전 준비

- JDK 21
- Docker와 Docker Compose
- 사용할 로컬 DB 계정·비밀번호

아래 절차는 현재 설정 파일을 기준으로 작성했습니다. 이 README 작성 과정에서는 애플리케이션 실행과 테스트 결과를 검증하지 않았습니다.

### 환경변수 설정

저장소 루트에서 예시 파일을 복사합니다.

```bash
cp .env.example .env
```

`.env`의 값을 로컬 환경에 맞게 수정합니다.

| 변수 | 용도 |
|---|---|
| `MYSQL_PORT` | 호스트에서 접속할 MySQL 포트 |
| `MYSQL_DATABASE` | 로컬 애플리케이션 DB 이름 |
| `MYSQL_USER` | 애플리케이션 DB 계정 |
| `MYSQL_PASSWORD` | 애플리케이션 DB 계정 비밀번호 |
| `MYSQL_ROOT_PASSWORD` | 로컬 MySQL root 비밀번호 |

`.env`는 Git 추적 대상에서 제외되어 있습니다.

### MySQL 실행

```bash
docker compose -f compose.local.yaml up -d
docker compose -f compose.local.yaml ps
```

MySQL 서비스의 상태가 `healthy`인지 확인합니다.

### 애플리케이션 실행

Spring 애플리케이션에도 환경변수를 전달해야 합니다. 터미널에서 실행할 경우, 직접 작성한 `.env`가 셸에서 읽을 수 있는 형식인지 확인한 뒤 다음과 같이 실행합니다.

```bash
set -a
source .env
set +a

./gradlew bootRun --args='--spring.profiles.active=local'
```

IDE에서 실행할 경우 같은 환경변수를 실행 구성에 등록하고 활성 프로필을 `local`로 지정합니다.

서버 시작 여부는 실행 로그의 `Started OneclickmeApplication` 메시지로 확인합니다. 현재 브랜치에는 서비스 기능을 확인할 도메인 API가 없습니다.

### 테스트

현재 테스트 코드는 애플리케이션 컨텍스트 로딩 테스트 1개입니다. 도메인별 성공·실패 동작을 검증하는 테스트는 구현 예정입니다.

`test` 프로필은 다음 구성을 사용합니다.

- DB 이름: `oneclickmeet_test`
- 접속 정보: `MYSQL_PORT`, `MYSQL_USER`, `MYSQL_PASSWORD`
- 선택 설정 파일: 저장소 루트의 `.env.local`
- 스키마 설정: `create-drop`

테스트 전에 별도 테스트 DB와 계정 권한을 준비하고, 접속 정보를 환경변수로 전달하거나 `.env.local`에 설정해야 합니다. 현재 Compose 설정만으로 테스트 DB와 권한이 함께 만들어지지는 않습니다.

테스트 클래스는 `test` 프로필을 활성화하도록 설정되어 있습니다.

```bash
./gradlew test
```

### 자동화 상태

현재 CI 워크플로는 `main` 대상 PR과 push에서 MySQL 8.4 서비스를 실행하고, `test` 프로필로 `./gradlew build`를 수행하도록 구성되어 있습니다. 빌드 과정에는 테스트와 애플리케이션 패키징이 포함됩니다.

dev 서버 자동 배포는 아직 구성하지 않았습니다. 실제 CI 실행 성공 여부와 서비스 동작 검증 결과는 이번 문서 작성 과정에서 확인하지 않았습니다.
